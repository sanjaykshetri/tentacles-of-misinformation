DATASET
-------
  Source           : FakeNewsNet (PolitiFact + GossipCop)
  Raw articles     : 23,196
  After cleaning   : 21,724  (1,472 removed — 6.3%)
  Train set        : 17,379 articles  (80%)
  Validation set   :  4,345 articles  (20%)
  Split strategy   : Stratified random, random_state=42
  Label balance    : 76.1% real  /  23.9% fake
  Class imbalance  : Addressed via class_weight='balanced'

FEATURE SETS
------------
  TF-IDF
    Vectorizer      : sklearn TfidfVectorizer
    max_features    : 10,000  (effective vocabulary: 6,422 tokens)
    ngram_range     : (1, 2)   unigrams + bigrams
    min_df          : 2
    sublinear_tf    : True
    Matrix shape    : 17,379 × 6,422  (sparse)
    Density         : 0.00131

  Psycholinguistic  (13 features)
    title_length_words        — word count of headline
    title_length_chars        — character count of headline
    sentiment_compound        — VADER compound sentiment [-1, 1]
    sentiment_positive        — VADER positive score
    sentiment_negative        — VADER negative score
    subjectivity              — TextBlob subjectivity [0, 1]
    flesch_kincaid_grade      — reading grade level
    ari                       — Automated Readability Index
    lexical_diversity         — type/token ratio
    certainty_terms           — count of certainty-language markers
    hedging_terms             — count of hedging-language markers
    emotional_intensifiers    — count of emotional amplifiers
    certainty_hedging_ratio   — certainty_terms / (hedging_terms + 1)

    Tools: VADER (sentiment), TextBlob (subjectivity), textstat (readability)
    Scaling: StandardScaler (fit on train, applied to val)

SPREAD MODEL — SEIR Epidemic Simulation
================================================================
  Type             : SEIR differential equation model
                     calibrated to FakeNewsNet cascade data

  Parameters (fitted via scipy.optimize.minimize, L-BFGS-B):
    β  (transmission rate)   : 0.0153  — per-contact spread probability
    σ  (exposure rate)       : 0.20    — fixed (prior literature)
    γ  (recovery rate)       : 0.0870  — debunking / disengagement rate
    R₀ = β / γ              : 0.176   — sub-epidemic threshold (< 1)

  Simulation population     : 1,000,000 (representative)
  Simulation period         : 180 days

  Baseline:
    Peak infected fraction   : 0.07% at day ~8

  Intervention (β↓20%, γ↑30%):
    Peak infected fraction   : 0.06% at day ~7
    Relative peak reduction  : ~23%
